# Deep Links для нотификаций

Документация по использованию deep links в приложении Plesury для навигации из push-нотификаций.

## Схема URL

Все deep links используют схему: `plesury://`

## Список доступных Deep Links

### 1. Главный экран (Today)
**URL:** `plesury://today`  
**Параметры:** нет  
**Требует авторизации:** да  
**Описание:** Открывает главный экран приложения (Dashboard)  
**Использование:** Для нотификаций общего характера, напоминаний

---

### 6. Экран статьи
**URL:** `plesury://article?id={articleId}`  
**Параметры:**

**Требует авторизации:** да  
**Описание:** Открывает экран просмотра статьи  
**Использование:** Для нотификаций о новых статьях, рекомендуемых статьях

**Примеры:**
- `plesury://article?id=123`
- `plesury://article?id=456`

---

**Параметры:**

## Использование в коде

### Импорт утилит

```typescript
import { DeepLinkBuilder, parseDeepLink, DEEP_LINKS } from '@app/navigation/deepLinks';
```

### Построение Deep Links

```typescript
// Статья
const articleLink = DeepLinkBuilder.article('123');
// Результат: "plesury://article?id=123"

// Опрос
const surveyLink = DeepLinkBuilder.survey('456');
// Результат: "plesury://survey?id=456"

// Опрос (пользователь может начать прохождение со страницы опроса)
const surveyLink = DeepLinkBuilder.survey('456');
// Результат: "plesury://survey?id=456"
// Примечание: DeepLinkBuilder.surveyQuestions() также перенаправляет на survey

// Проверка email
const checkEmailLink = DeepLinkBuilder.checkEmail('user@example.com');
// Результат: "plesury://check-email?email=user%40example.com"

// Роут без параметров
const todayLink = DeepLinkBuilder.route(Routes.TODAY);
// Результат: "plesury://today"
```

### Парсинг Deep Links

```typescript
const url = 'plesury://article?id=123';
const parsed = parseDeepLink(url);

if (parsed) {
  console.log(parsed.route); // Routes.ARTICLE
  console.log(parsed.params); // { id: '123' }
}
```

## Примеры использования в нотификациях

### 1. Нотификация о новой статье
```json
{
  "title": "Новая статья",
  "body": "Прочитайте нашу новую статью",
  "data": {
    "deepLink": "plesury://article?id=123"
  }
}
```

### 2. Нотификация о новом опросе

```json
  "body": "Пройдите опрос",
  "data": {
    "deepLink": "plesury://survey?id=456"
  }
}
```

### 3. Нотификация-напоминание
```json

  "title": "Напоминание",
  "body": "Не забудьте выполнить активности",
  "data": {
    "deepLink": "plesury://activities"
  }
```

### 4. Нотификация о подписке

```json
  "body": "Обновите подписку",
  "data": {
    "deepLink": "plesury://subscription-settings"
  }
}
```

## Обработка Deep Links в приложении

Deep links обрабатываются автоматически через React Navigation Linking API. При получении нотификации с deep link, приложение автоматически откроет соответствующий экран.

**Важно:**
- Если deep link требует авторизации, но пользователь не авторизован, приложение перенаправит на экран входа
- Параметры передаются автоматически в соответствующие экраны
- Для `SURVEY_QUESTIONS` используется `surveyId` вместо полного объекта `survey` (объект загружается на экране)

## Настройка в app.json

Для работы deep links необходимо настроить схему в `app.json`:

```json
{
  "expo": {
    "scheme": "plesury"
  }
}
```

## Тестирование Deep Links

### iOS Simulator
```bash
xcrun simctl openurl booted "plesury://article?id=123"
```

### Android Emulator
```bash
adb shell am start -W -a android.intent.action.VIEW -d "plesury://article?id=123" app.plesury
```

### Через терминал (если приложение запущено)
```bash
# iOS
xcrun simctl openurl booted "plesury://today"

# Android
adb shell am start -W -a android.intent.action.VIEW -d "plesury://today" app.plesury
```
