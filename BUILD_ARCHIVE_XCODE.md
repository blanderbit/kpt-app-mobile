# Инструкция по сборке архива в Xcode

## Шаги для создания архива с правильной подписью:

1. **Откройте проект в Xcode:**
   - Проект уже открыт: `Plesury.xcworkspace`

2. **Выберите схему и устройство:**
   - В верхней панели Xcode выберите схему: **Plesury**
   - Выберите устройство: **Any iOS Device** (или **Generic iOS Device**)

3. **Проверьте настройки подписи:**
   - Выберите проект `Plesury` в навигаторе слева
   - Выберите target `Plesury`
   - Перейдите на вкладку **"Signing & Capabilities"**
   - Убедитесь, что:
     - ✅ **"Automatically manage signing"** включено
     - ✅ Выбран правильный **Team** (с вашим App Store Connect аккаунтом)
     - ✅ **Bundle Identifier**: `app.plesury`

4. **Создайте архив:**
   - В меню Xcode: **Product → Archive**
   - Дождитесь завершения сборки (может занять несколько минут)

5. **Экспортируйте IPA:**
   - После создания архива откроется окно **Organizer**
   - Выберите только что созданный архив
   - Нажмите **"Distribute App"**
   - Выберите **"App Store Connect"**
   - Нажмите **"Next"**
   - Выберите **"Upload"** (для загрузки в TestFlight)
   - Нажмите **"Next"**
   - Выберите автоматическую подпись
   - Нажмите **"Next"** и дождитесь экспорта
   - Нажмите **"Upload"** для загрузки в App Store Connect

6. **Альтернатива - Сохранить IPA локально:**
   - В окне экспорта выберите **"Export"** вместо **"Upload"**
   - Выберите папку для сохранения
   - IPA файл будет сохранен локально
   - Затем можно загрузить через **Transporter**

---

## Если возникают проблемы с подписью:

1. **Очистите Derived Data:**
   - Xcode → Preferences → Locations
   - Нажмите стрелку рядом с Derived Data
   - Удалите папку для проекта Plesury

2. **Обновите provisioning profiles:**
   - Xcode → Preferences → Accounts
   - Выберите ваш аккаунт
   - Нажмите **"Download Manual Profiles"**

3. **Проверьте сертификаты:**
   - Убедитесь, что у вас есть **Apple Distribution** сертификат
   - Если нет - Xcode создаст его автоматически при архивации

---

## После экспорта:

- **Если выбрали Upload:** Билд автоматически загрузится в App Store Connect
- **Если выбрали Export:** IPA файл будет в выбранной папке, можно загрузить через Transporter

---

**Примечание:** Xcode автоматически подберет правильные provisioning profiles и сертификаты для App Store Connect, если у вас настроен аккаунт.
